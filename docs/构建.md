# 构建 Ivy connect v1.0.0

在 Windows x64 上安装 .NET 10 SDK。以下命令在源码仓库根目录执行。

```powershell
dotnet publish .\src\IvyConnect.Windows.csproj -c Release -r win-x64 --self-contained true -p:PublishProfile=PortableFolder -o ".\out\Ivy connect 1.0"
```

发布目录中的 `Ivy connect.exe` 是 WinForms 的实际入口，构建启动类为 `LabEntry`。随目录发布全部依赖、Microsoft 的 `LICENSE.dotnet.txt` 和 `ThirdPartyNotices.dotnet.txt`。默认图标和遮罩作为程序集资源，运行时可从任意目录打开完整发布。

`PortableSingle.pubxml` 保留用作独立实验。历史 .NET Framework 项目 `QQWindowLab.csproj`、`构建.cmd` 和旧启动器源码用于复查旧版。正式 v1.0.0 使用 SDK 工程和 `PortableFolder`。

本轮只统一发布身份、关于信息、发布输出与首启备份。QQ 传输、模型协议和状态机代码沿用 v0.8.0。源码历史为审核后的快照导入，提交日期记录本次归档时间。
