# Ivy connect v1.0.0 正式验收

本次在 Windows 11 x64 家庭版 26200、官方 QQ NT 9.9.36.53644 上检查。构建基线为桌面研究目录的 v0.8.0 文件夹与单文件实验版源码。本次使用 .NET SDK 10.0.404、Windows Desktop 10.0.15 和 Release win-x64 自包含文件夹发布。

| 检查 | 结果 |
| --- | --- |
| 桌面直接启动 | 通过。Windows ShellExecute 打开最终目录的 `Ivy connect.exe`，进程路径匹配。标题为 Ivy connect 1.0，产品版本为 1.0.0，文件版本为 1.0.0.0。 |
| 独立目录 | 通过。完整复制到含空格与中文的路径，在另一工作目录从实际 EXE 启动。包内包含 CoreCLR 和 Windows Forms 运行库。 |
| 互斥 | 通过。正式版运行期间，从不同目录启动第二份正式程序和从研究目录启动 v0.7.0，均被已有实例拒绝。 |
| 现有资料 | 通过。三份既有 DPAPI 数据文件在启动前后逐字节等同，自动生成的正式版首启备份与原文件逐项匹配。配置、会话账本及原有待确认状态按原文件保留。 |
| 离线回归 | 7 组测试、119 项通过记录。覆盖绑定/窗口变化拦截、五位验证码、遮罩、路由、暂停/停止后的迟到回答、历史及自身消息处理、待确认恢复和防重发。模型模拟覆盖协议、上下文、思考与正文解析和网络配置。 |
| 界面 | 使用隔离演示数据截图。验证主操作区、模型设置分组、验证码方向说明以及最小化到托盘和还原。 |
| 真实模型 | 已保存的官方 DeepSeek 配置通过连接探针及实际最终回答检查；本次模型调用使用独立测试输入。 |
| 本次真实 QQ | 只读检查触发「当前不能通过原验证码气泡或连续消息复核会话，请重新核验」。程序依照已有核验条件停止。未重新绑定、未提交 QQ 消息，也未宣称本次完成新的 QQ 收发闭环。 |
| 历史真实 QQ | v0.8.0 实验对应报告记录已授权单私聊的两轮模型上下文、本地气泡、各轮对端收件，以及展开失焦和图片遮罩测试。此项引用先前证据。 |
| 签名和扫描 | 主程序未签名。Windows Defender 状态提供程序加载失败，命令行自定义扫描因服务错误退出。当前没有完成 Defender 扫描。 |

文件夹版在本机运行，尚无一台未预装 .NET 的干净 Windows 对照机。正式 Release 下载采用文件夹版。v0.8.0 的单文件原包继续在本机保存。真实最小化、群聊、多联系人路由与长期运行未纳入本次验收。
